# 🔐 Password Generator

A secure random password generator in Python with customizable options.

## 🇺🇸 English

### Features
- Customizable password length (8-50 characters)
- Option to include letters, numbers, and symbols
- Generates 3 password suggestions at once
- Minimum length warning for security
- Error handling for invalid inputs

### How to Use
```bash
python gerador_senhas.py
```

### Example
```
🔐 GERADOR DE SENHAS SEGURAS
==================================================

⚙️  CONFIGURAÇÕES DA SENHA:
--------------------------------------------------

📏 Tamanho da senha (8-50): 16

🔤 TIPOS DE CARACTERES:
Incluir letras? (s/n): s
Incluir números? (s/n): s
Incluir símbolos? (s/n): s

==================================================
🔑 SUAS SENHAS GERADAS:
==================================================

Opção 1: aB3$kL9!mN2@pQ7z
Opção 2: xY7#rT4&wE1*qS8v
Opção 3: mK2@nB6!pL9$cD3f
```
