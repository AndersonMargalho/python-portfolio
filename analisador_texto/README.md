# 📝 Text Analyzer

A Python tool for text analysis and string manipulation.

## 🇺🇸 English

### Features
- Character count (with and without spaces)
- Word count (total and longest word)
- Vowel/consonant analysis (including accents)
- Sentence and paragraph count
- String manipulation

### How to Use
```bash
python analisador_texto.py
```

### Example
```
📄 Digite ou cole seu texto abaixo:
Olá, mundo! Este é um teste.

📊 RESULTADOS DA ANÁLISE:
📏 CARACTERES:
   • Total: 33
   • Sem espaços: 27
📝 PALAVRAS:
   • Total: 7
   • Mais longa: "mundo" (5 letras)
📄 ESTRUTURA:
   • Frases: 2
   • Parágrafo(s): 1
🔤 LETRAS:
   • Vogais: 12
   • Consoantes: 14
```
