# 🎲 Guessing Game

An interactive number guessing game with scoring system and performance feedback.

## 🇺🇸 English

### Features
- Random number generation (1-100)
- Interactive guessing with hints (higher/lower)
- Attempt counter
- Performance rating (Excellent, Very Good, Can Improve)
- Input validation and error handling

### How to Use
```bash
python jogo_adivinhacao.py
```

### Example
```
🎲 JOGO DE ADIVINHAR O NÚMERO
==================================================

📜 REGRAS DO JOGO:
- Vou pensar em um número entre 1 e 100
- Você tenta adivinhar qual é
- Eu te digo se é MAIOR ou MENOR
- Tente acertar em menos tentativas possível!
==================================================

🤔 Seu palpite: 50
📈 MAIS ALTO! Tente um número maior.

🤔 Seu palpite: 75
📉 MAIS BAIXO! Tente um número menor.

🤔 Seu palpite: 63
🎉 PARABÉNS! Você acertou!
📊 Número secreto: 63
📊 Tentativas: 3
🏆 Desempenho: EXCELENTE!
```
