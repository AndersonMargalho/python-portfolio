# 🔒 Hash Checker

A data integrity tool using SHA-256 to detect file tampering.

## 🇺🇸 English

### Features
- SHA-256 hash generation for any file
- Memory-efficient (reads file in chunks)
- File not found error handling
- Useful for verifying file integrity

### How to Use
```bash
python verificador_hash.py
```

### Example
```
Digite o nome/caminho do arquivo: documento.pdf
O Hash SHA-256 do arquivo é: a3f5b8c2d1e4f7a9b6c3d8e1f4a7b2c5d8e1f4a7b2c5d8e1f4a7b2c5d8e1f4a7
```

### Use Cases
- Verify downloaded files (compare with official hash)
- Detect file tampering
- Ensure data integrity in backups
- Validate file transfers
