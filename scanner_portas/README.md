# 🌐 Port Scanner

A network tool to identify open services and security vulnerabilities.

## 🇺🇸 English

### Features
- TCP port scanning on a target IP
- Configurable port list
- Connection timeout handling
- Clear output (open/closed ports)

### How to Use
```bash
python scanner_portas.py
```

### Example
```
Escaneando o alvo: 127.0.0.1

Porta 21: ABERTA ✅
Porta 22: ABERTA ✅
Porta 80: ABERTA ✅
Porta 443: ABERTA ✅
Porta 8080: ABERTA ✅
```

### ⚠️ Warning
Use only on networks you own or have explicit permission to test. Unauthorized port scanning is illegal in many jurisdictions.

### Common Ports
| Port | Service |
|------|---------|
| 21 | FTP |
| 22 | SSH |
| 80 | HTTP |
| 443 | HTTPS |
| 8080 | HTTP Alternate |
