# 🌡️ Temperature Converter

A Python tool for converting temperature units with a menu-based interface.

## 🇺🇸 English

### Features
- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- Loop-based interface with error handling

### How to Use
```bash
python conversor_temperatura.py
```

### Example
```
🔄 ESCOLHA A CONVERSÃO:
1. Celsius → Fahrenheit
2. Fahrenheit → Celsius
3. Celsius → Kelvin
4. Kelvin → Celsius
5. Sair

Digite a opção (1-5): 1
🌡️  Digite a temperatura: 25

✅ 25.0°C = 77.00°F
```
