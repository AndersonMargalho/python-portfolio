### 🔑 AI Project Setup (`analisador_ia`)
1. Get a free API key at [Google AI Studio](https://aistudio.google.com/)
2. Create a `.env` file in the repository root with: `GEMINI_API_KEY=your-key-here`
3. Install dependencies: `pip install -r analisador_ia/requirements.txt`
4. Run: `python analisador_ia/analisador_ia.py`

> Never commit `.env` — it is listed in `.gitignore`.
